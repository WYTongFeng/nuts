# 第二版验证（2026-10-23）

## 已实现

独立生成 1 或 3 个候选、三档强度、可选作者写作样本、字面保留检查、独立语义复核、同引擎前后参考评分、保留原文兜底、重复候选提示、请求间停止、逐版本外部分数手工记录与 JSON 导出。

## 证据

- 48 个 Python 测试通过（原 36 个加上质量检查和审阅接口测试）。
- JS 语法检查、Python 编译和 Git 空白检查通过。
- 浏览器使用独立模拟 Ollama 服务，确认三候选出现、重复标记、少于 80 词不评分、语义复核状态、外部四项初始全部未测。
- 浏览器录入一个测试值 37.5 后显示仅记录 1/4；切到另一个候选恢复未测，证明记录按版本隔离。该测试值不是任何平台的实测结果，未保存到交付包。
- 浏览器另以 94 词原文测试故意过短的模拟候选，页面保留原文并显示原文基线，未把缺失信息后的短结果当成推荐。
- 发现短文本默认说明错误地写成“评分较低”，已改成“不比较检测分数，仅按自动检查选择”。

## 未验证

- 本机没有运行真实 Ollama 模型，没有测得新版实际生成质量、速度或评分改善幅度。
- 未向 Turnitin、GPTZero、ZeroGPT、QuillBot 提交文本，四个平台目标达成情况均未知。
- 通过自动测试只证明逻辑分支正常，不等于改写符合原意，也不等于检测分数降低。
- 自我语义复核仍使用生成模型，存在共同盲点；数字、引用等检查只覆盖字面形式。代码未把“检查通过”称为语义正确的证明。
- 本地候选筛选用规则模型，存在偏向自身规则的风险；需要独立外部实测才能评价跨平台效果。
